アルゴリズムについて

バブルソート

時間計算量: O(n²) - 最悪・平均、O(n) - 最良

空間計算量: O(1)

安定性: 安定

説明: 隣接する要素を比較し、順序が逆であれば交換する操作を繰り返します。最大の要素が徐々に配列の末尾に「浮かび上がる」様子から「バブル」という名前がついています。

特徴:

  • 実装が非常にシンプル
  • 小規模なデータセットに適している
  • ほぼソート済みのデータに対しては効率的
  • 大規模なデータには不向き

実装例 (JavaScript)

async function bubbleSort(array) {
    const n = array.length;
    
    for (let i = 0; i < n - 1; i++) {
        for (let j = 0; j < n - i - 1; j++) {
            // 隣接要素を比較
            comparisons++;
            
            if (array[j] > array[j + 1]) {
                // 交換
                [array[j], array[j + 1]] = [array[j + 1], array[j]];
                swaps++;
                
                // 可視化のための待機
                await sleep(delay);
            }
        }
    }
    
    return array;
}
