## 📖 概要

このドキュメントサイトは、開発者がゲームを実装する際の包括的なガイドとして機能します。以下の内容が含まれています：

- **ゲーム設計の詳細説明** - ゲーム目標、スコアリング基準、プレイヤーアクション
- **クラス設計** - Aquarium、Tank、Fish、Equipment、Decoration、Itemクラスの詳細
- **UML図** - クラス関係図とモジュール依存関係図（SVG形式）
- **モジュール構造** - models.py、logic.py、ui.pyの責務とサンプルコード
- **CUIコマンドリファレンス** - 全コマンドの使用方法と例
- **開発ガイダンス** - 実装手順、推奨ツール、テスト戦略

## 🚀 ローカルプレビュー

このドキュメントサイトは完全に静的なHTML/CSS/JavaScriptで構成されており、追加の依存関係なしで動作します。

### 方法1: Python HTTPサーバー（推奨）

```bash
# このディレクトリに移動
cd docs/game-design-site

# Pythonの組み込みHTTPサーバーを起動
python -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

### 方法2: 直接ファイルを開く

```bash
# index.htmlをブラウザで直接開く（相対パスが使用されているため動作します）
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### 方法3: VS Code Live Server拡張機能

1. VS Codeで`index.html`を開く
2. 右クリックして "Open with Live Server" を選択

## 🔧 カスタマイズ

### スタイルの変更

`styles.css`の`:root`セクションでカラーパレットをカスタマイズできます：

```css
:root {
    --primary-color: #0ea5e9;    /* メインカラー */
    --secondary-color: #8b5cf6;  /* セカンダリカラー */
    --accent-color: #f59e0b;     /* アクセントカラー */
    /* ... */
}
```

### コンテンツの追加

新しいセクションを追加する場合：

1. `index.html`に`<section class="doc-section" id="new-section">`を追加
2. セクション内に`<h2>`見出しを追加
3. `main.js`が自動的に目次を更新します
