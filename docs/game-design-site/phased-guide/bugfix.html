💡 バグ対策とは？
プログラミングにおいて、バグ（不具合）は避けられません。重要なのは、バグを早く見つけ、効率的に修正し、再発を防ぐスキルを身につけることです。

学べる内容：

  • ✅ デバッグ技術: バグを特定するための実践的な手法
  • ✅ よくあるバグパターン: 遭遇しやすいバグとその解決策
  • ✅ ロギング: プログラムの動作を記録して分析
  • ✅ pdbの使い方: Pythonのデバッガの実践的な使用法
  • ✅ パフォーマンス最適化: 遅い処理を高速化する方法
  • ✅ リファクタリング: コードを整理して保守性を向上
  • ✅ コードレビューのポイント: 自分のコードを見直す観点
📌 このページの使い方
Phase 0-5の開発中に問題が発生したら、このページに戻ってきて該当するセクションを読みましょう。すべてを一度に学ぶ必要はありません。

🤔 なぜバグ対策が重要なのか（Why Important）

1. なぜデバッグスキルが必須なのか？

プログラミングにおけるデバッグの重要性：

  • 現実: プログラミング時間の50-70%はデバッグに費やされる
  • 生産性: デバッグが速いと開発スピードが劇的に向上
  • 品質: バグを早期発見することで、重大な問題を防げる
  • 学習: バグから学ぶことで、プログラミングスキルが向上

2. なぜロギングが必要なのか？

print文だけでは不十分な理由：

  • 永続性: ログはファイルに残せるが、print文は消えてしまう
  • レベル分け: DEBUG、INFO、WARNING、ERRORで重要度を分類できる
  • 本番環境: print文は本番で邪魔だが、ログは必要な情報だけ出力できる
  • 分析: ログファイルを後から解析して問題を特定できる

3. なぜリファクタリングが大切なのか？

コードを整理する理由：

  • 可読性: 後から読んだときに理解しやすい
  • 保守性: 修正や機能追加がしやすくなる
  • バグ削減: コードが整理されていると、バグが混入しにくい
  • チーム作業: 他の人が読んでも理解できる

🛠️ デバッグの進め方（How to Debug）

効果的なデバッグは、体系的なアプローチで行います。以下のステップで進めましょう。

1問題を再現する

バグを確実に再現できる手順を見つけます。

  • どの操作でバグが発生するか
  • どのような条件でバグが起きるか
  • エラーメッセージは何か
💡 再現できないバグは修正できません
まずは「100%再現できる手順」を見つけることが最優先です。

2問題を切り分ける

バグの原因がどこにあるか絞り込みます。

  • 二分探索: コードの前半と後半、どちらに問題があるか
  • 最小再現コード: 問題を再現する最小限のコードを作る
  • 仮説検証: 「ここが怪しい」という仮説を立てて検証

3デバッグツールを使う

print文だけでなく、専用ツールを活用します。

  • pdb: ブレークポイントを設定して変数を調査
  • logging: プログラムの実行フローを記録
  • IDE: VS Codeなどのデバッガ機能を活用

4修正して検証する

修正後は必ず動作確認します。

  • 元の再現手順でバグが直っているか確認
  • 修正によって他の部分が壊れていないか確認（リグレッションテスト）
  • 同じバグが他の箇所にもないか確認

5再発を防ぐ

同じバグが二度と起きないようにします。

  • テストを追加: そのバグを検出するテストケースを書く
  • コードレビュー: なぜバグが起きたか分析
  • ドキュメント化: 同じ間違いを繰り返さないようメモ

🔧 実践的なツールの使い方（Practical Tools）

1. pdb（Python Debugger）の基本

pdbは対話的にコードをデバッグできる強力なツールです：

# デバッグしたい箇所に挿入
import pdb; pdb.set_trace()  # ← ここでプログラムが一時停止

# よく使うコマンド：
# n (next)      : 次の行へ
# s (step)      : 関数の中に入る
# c (continue)  : 次のブレークポイントまで実行
# p 変数名       : 変数の値を表示
# pp 変数名      : 変数を整形して表示
# l (list)      : 現在のコードを表示
# q (quit)      : デバッガを終了

実例:

def calculate_happiness(fish):
    import pdb; pdb.set_trace()  # ← ここで停止
    health = fish.health
    hunger = fish.hunger
    happiness = (health * 0.5) + ((100 - hunger) * 0.5)
    return happiness

# 実行すると、set_trace()の行で停止し、
# 変数の値を確認したり、一行ずつ実行できます

2. loggingモジュールの設定

適切なログ設定で、問題の追跡が容易になります：

import logging

# ログの設定（プログラム起動時に1回だけ実行）
logging.basicConfig(
    level=logging.DEBUG,  # DEBUG, INFO, WARNING, ERROR, CRITICAL
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('aquarium.log'),  # ファイルに出力
        logging.StreamHandler()  # コンソールにも出力
    ]
)

logger = logging.getLogger(__name__)

# 使用例
logger.debug("魚を追加: %s", fish.name)  # 詳細情報
logger.info("セーブ完了")               # 一般情報
logger.warning("水質が悪化しています")   # 警告
logger.error("ファイル読み込み失敗")     # エラー
logger.critical("致命的エラー")          # 重大エラー

3. assertを使った防御的プログラミング

期待する条件をassertで明示的にチェック：

def add_fish(self, tank_id: int, fish: Fish):
    """魚を水槽に追加"""
    # 前提条件のチェック
    assert 0 <= tank_id < len(self.tanks), f"無効な水槽ID: {tank_id}"
    assert fish is not None, "fishがNoneです"
    assert isinstance(fish, Fish), f"fishはFishクラスのインスタンスである必要があります: {type(fish)}"
    
    tank = self.tanks[tank_id]
    assert len(tank.fish_list) < tank.capacity, "水槽が満杯です"
    
    tank.add_fish(fish)
    logger.info(f"魚を追加しました: {fish.name} → 水槽{tank_id}")

assertは開発中にバグを早期発見するのに役立ちます。

🔍 よくあるバグパターンと解決策

パターン1: 参照の共有問題

問題: リストや辞書をデフォルト引数にすると、意図しない共有が起きる

❌ 悪い例:
def __init__(self, fish_list=[]):  # ← すべてのインスタンスで共有される！
    self.fish_list = fish_list

✅ 良い例:
def __init__(self, fish_list=None):
    self.fish_list = fish_list if fish_list is not None else []

パターン2: 浮動小数点の比較

問題: 浮動小数点数を==で比較すると誤差で一致しないことがある

❌ 悪い例:
if temperature == 25.0:  # ← 24.999999999999とは一致しない

✅ 良い例:
import math
if math.isclose(temperature, 25.0, rel_tol=1e-9):
    # 許容誤差内で一致

パターン3: None チェック忘れ

問題: 変数がNoneの可能性を考慮していない

❌ 悪い例:
fish = tank.get_fish(fish_id)
print(fish.name)  # ← fishがNoneだとAttributeError

✅ 良い例:
fish = tank.get_fish(fish_id)
if fish is not None:
    print(fish.name)
else:
    print("魚が見つかりません")

パターン4: リストの変更中にイテレーション

問題: ループ中にリストを変更すると予期しない動作になる

❌ 悪い例:
for fish in tank.fish_list:
    if fish.is_dead():
        tank.fish_list.remove(fish)  # ← ループ中の変更は危険

✅ 良い例:
tank.fish_list = [f for f in tank.fish_list if not f.is_dead()]
# または
for fish in tank.fish_list[:]:  # コピーをループ
    if fish.is_dead():
        tank.fish_list.remove(fish)

⚡ パフォーマンス最適化のヒント

1. 測定してから最適化する

鉄則: 推測で最適化せず、実測データに基づいて最適化する

import time

# 処理時間の計測
start = time.time()
# ... 処理 ...
end = time.time()
print(f"処理時間: {end - start:.3f}秒")

2. よくある最適化ポイント

  • ループの最適化: 不要な計算をループの外に出す
  • データ構造の選択: リストよりセットや辞書が速い場合がある
  • キャッシング: 同じ計算を繰り返さない
  • 遅延評価: 必要になるまで計算しない
❌ 遅い例:
for fish in all_fish:
    if fish.species in [s for s in species_list]:  # 毎回リスト作成
        process(fish)

✅ 速い例:
species_set = set(species_list)  # 一度だけセット化
for fish in all_fish:
    if fish.species in species_set:  # O(1)の検索
        process(fish)

🔨 リファクタリングの指針

リファクタリングすべきサイン（コードの臭い）

  • ❌ 長すぎる関数: 50行を超える関数は分割を検討
  • ❌ 重複コード: 同じコードが2箇所以上にある
  • ❌ 深すぎるネスト: if文が3段階以上ネストしている
  • ❌ マジックナンバー: 意味不明な数値がコードに直接書かれている
  • ❌ 長すぎるパラメータリスト: 関数の引数が5個以上

リファクタリングの基本テクニック

1. 関数の抽出

❌ リファクタリング前:
def process_tank(tank):
    # 水質チェック
    if tank.temperature < 18 or tank.temperature > 28:
        print("警告: 温度異常")
    if tank.ph < 6.0 or tank.ph > 8.0:
        print("警告: pH異常")
    # ... 長いコード

✅ リファクタリング後:
def check_water_quality(tank):
    """水質チェックを別関数に抽出"""
    if tank.temperature < 18 or tank.temperature > 28:
        print("警告: 温度異常")
    if tank.ph < 6.0 or tank.ph > 8.0:
        print("警告: pH異常")

def process_tank(tank):
    check_water_quality(tank)
    # ... 他の処理

2. マジックナンバーの定数化

❌ リファクタリング前:
if fish.hunger > 80:  # 80って何？
    fish.health -= 10  # 10って何？

✅ リファクタリング後:
HUNGER_THRESHOLD = 80  # 空腹警告レベル
HEALTH_DECREASE_AMOUNT = 10  # 健康減少量

if fish.hunger > HUNGER_THRESHOLD:
    fish.health -= HEALTH_DECREASE_AMOUNT

📝 まとめと継続的改善

🎯 デバッグとリファクタリングの習慣

  • ✅ 早期発見: こまめにテストして、バグを早く見つける
  • ✅ 記録: ログを活用して、問題の原因を追跡
  • ✅ 整理: コードが汚くなったら、すぐにリファクタリング
  • ✅ 学習: バグから学び、同じ間違いを繰り返さない
  • ✅ レビュー: 定期的に自分のコードを見直す

継続的な改善のサイクル

1. コードを書く
   ↓
2. テストする
   ↓
3. バグを見つける
   ↓
4. デバッグして修正
   ↓
5. リファクタリング
   ↓
1に戻る（繰り返し）

2完全なFishクラスの実装

Phase 0の簡易版から、健康状態や成長など、本格的な機能を追加します。

💻 完全なコード（models/fish.py）：

"""
魚クラス - Phase 1 完全版
健康管理、成長、状態変化を含む
"""

from dataclasses import dataclass, field
from typing import Dict, Optional
import uuid
from datetime import datetime


@dataclass
class Fish:
    """
    水族館の魚を表すクラス（完全版）
    
    Phase 1では健康状態、成長、ストレス管理を含む
    """
    # 基本情報
    species: str  # 種類（例: "goldfish", "clownfish"）
    name: str = ""  # 個体名
    fish_id: str = field(default_factory=lambda: str(uuid.uuid4())[:8])
    
    # 状態パラメータ（0-100）
    health: int = 100  # 健康度
    hunger: int = 0  # 空腹度（高いほど空腹）
    stress_level: int = 0  # ストレスレベル
    
    # 成長パラメータ
    age: int = 0  # 年齢（日数）
    size: float = 5.0  # サイズ（cm）
    growth_rate: float = 0.01  # 成長速度
    
    # 飼育要件
    min_temperature: float = 20.0
    max_temperature: float = 28.0
    preferred_ph: float = 7.0
    ph_tolerance: float = 1.0  # pH許容範囲
    
    # 経済・ゲーム
    price: int = 100
    is_sick: bool = False
    birth_date: datetime = field(default_factory=datetime.now)
    
    def feed(self, amount: int = 20) -> None:
        """
        魚に餌を与える
        
        Args:
            amount: 餌の量（デフォルト20）
        """
        self.hunger = max(0, self.hunger - amount)
        
        # 食べ過ぎはストレス増加
        if self.hunger < -20:
            self.stress_level = min(100, self.stress_level + 5)
    
    def update_status(self, water_quality: Dict[str, float]) -> None:
        """
        環境に応じて魚の状態を更新
        
        Args:
            water_quality: 水質パラメータの辞書
        """
        # 空腹度の増加
        self.hunger = min(100, self.hunger + 5)
        
        # 空腹による健康への影響
        if self.hunger > 80:
            self.health = max(0, self.health - 5)
            self.stress_level = min(100, self.stress_level + 3)
        
        # 水質による影響
        temp = water_quality.get('temperature', 25.0)
        ph = water_quality.get('ph', 7.0)
        cleanliness = water_quality.get('cleanliness', 100)
        
        # 温度チェック
        if not (self.min_temperature <= temp <= self.max_temperature):
            self.health = max(0, self.health - 3)
            self.stress_level = min(100, self.stress_level + 5)
        
        # pHチェック
        ph_diff = abs(ph - self.preferred_ph)
        if ph_diff > self.ph_tolerance:
            self.health = max(0, self.health - 2)
            self.stress_level = min(100, self.stress_level + 3)
        
        # 清潔度チェック
        if cleanliness < 50:
            self.health = max(0, self.health - 2)
            self.stress_level = min(100, self.stress_level + 2)
        
        # 病気判定
        if self.health < 30:
            self.is_sick = True
        elif self.health > 70:
            self.is_sick = False
        
        # ストレスの自然減少（良好な環境では）
        if cleanliness > 80 and ph_diff < 0.5:
            self.stress_level = max(0, self.stress_level - 1)
    
    def grow(self) -> None:
        """魚を成長させる"""
        self.age += 1
        
        # サイズの増加（健康度が高いほど成長しやすい）
        if self.health > 50:
            growth = self.growth_rate * (self.health / 100)
            self.size += growth
    
    def calculate_happiness(self) -> int:
        """
        幸福度を計算
        
        Returns:
            int: 幸福度（0-100）
        """
        happiness = 100
        happiness -= self.hunger * 0.5
        happiness -= self.stress_level * 0.3
        happiness -= (100 - self.health) * 0.2
        
        return int(max(0, min(100, happiness)))
    
    def get_status_emoji(self) -> str:
        """状態を絵文字で表現"""
        if self.health < 30:
            return "💀"  # 瀕死
        elif self.health < 60:
            return "😢"  # 不調
        elif self.hunger > 70:
            return "😫"  # 空腹
        elif self.stress_level > 70:
            return "😰"  # ストレス
        elif self.health > 80 and self.hunger < 30:
            return "😊"  # 元気
        else:
            return "🙂"  # 普通
    
    def __str__(self) -> str:
        """文字列表現"""
        return f"{self.get_status_emoji()} {self.name or self.fish_id} ({self.species}) - HP:{self.health}"


# ===== テストコード =====
if __name__ == "__main__":
    print("🐠 魚クラス（完全版）のテスト開始")
    print("-" * 50)
    
    # テスト1: 魚の作成
    fish = Fish(species="goldfish", name="金太郎")
    print(f"✅ テスト1: {fish}")
    
    # テスト2: 餌やり
    fish.hunger = 50
    fish.feed(30)
    print(f"✅ テスト2: 餌やり後 - 空腹度:{fish.hunger}")
    
    # テスト3: 状態更新（良好な環境）
    good_water = {
        'temperature': 25.0,
        'ph': 7.0,
        'cleanliness': 90
    }
    fish.update_status(good_water)
    print(f"✅ テスト3: 良好な環境 - {fish}")
    
    # テスト4: 状態更新（悪い環境）
    bad_water = {
        'temperature': 15.0,  # 低すぎる
        'ph': 9.0,  # 高すぎる
        'cleanliness': 30  # 汚い
    }
    fish.update_status(bad_water)
    print(f"✅ テスト4: 悪い環境 - {fish}")
    
    # テスト5: 成長
    fish.health = 80
    fish.grow()
    print(f"✅ テスト5: 成長 - サイズ:{fish.size:.2f}cm, 年齢:{fish.age}日")
    
    # テスト6: 幸福度
    happiness = fish.calculate_happiness()
    print(f"✅ テスト6: 幸福度 - {happiness}/100")
    
    print("-" * 50)
    print("🎉 すべてのテスト完了！")

"""
水槽クラス - Phase 1 完全版
水質管理、容量制限、装備管理を含む
"""

from typing import List, Dict, Optional
from models.fish import Fish
import uuid


class Tank:
    """水槽クラス（完全版）"""
    
    def __init__(self, capacity: int = 100, name: str = ""):
        self.tank_id: str = str(uuid.uuid4())[:8]
        self.name: str = name or f"Tank-{self.tank_id}"
        self.capacity: int = capacity  # リットル
        
        # 水質パラメータ
        self.water_quality: Dict[str, float] = {
            'ph': 7.0,
            'temperature': 25.0,
            'cleanliness': 100.0,
            'oxygen': 100.0,
            'ammonia': 0.0,
        }
        
        # 収容物
        self.fish_list: List[Fish] = []
        self.equipment: List = []  # Equipment objects
        self.decorations: List = []  # Decoration objects
        
        # 統計
        self.days_since_cleaning: int = 0
        self.total_fish_deaths: int = 0
    
    def add_fish(self, fish: Fish) -> bool:
        """
        魚を追加（容量チェック付き）
        
        Returns:
            bool: 追加成功ならTrue
        """
        current_load = sum(f.size for f in self.fish_list)
        
        if current_load + fish.size > self.capacity:
            return False  # 容量オーバー
        
        self.fish_list.append(fish)
        return True
    
    def update_water_quality(self, days: int = 1) -> None:
        """水質を経時変化させる"""
        fish_count = len(self.fish_list)
        fish_load = sum(f.size for f in self.fish_list)
        
        # 清潔度の低下
        self.water_quality['cleanliness'] = max(0, 
            self.water_quality['cleanliness'] - 5 * days - fish_load * 0.1)
        
        # アンモニアの増加
        self.water_quality['ammonia'] = min(100,
            self.water_quality['ammonia'] + 2 * days + fish_count * 0.5)
        
        # 酸素の減少
        self.water_quality['oxygen'] = max(20,
            self.water_quality['oxygen'] - 3 * days - fish_count)
        
        self.days_since_cleaning += days
    
    def clean_tank(self) -> None:
        """水槽を清掃する"""
        self.water_quality['cleanliness'] = 100.0
        self.water_quality['ammonia'] = 0.0
        self.water_quality['oxygen'] = 100.0
        self.days_since_cleaning = 0
    
    def calculate_beauty_score(self) -> int:
        """美観スコアを計算"""
        score = self.water_quality['cleanliness'] * 0.5
        # 装飾によるボーナス（Phase 4で実装）
        return int(min(100, score))
    
    def get_capacity_ratio(self) -> float:
        """容量使用率を返す"""
        current_load = sum(f.size for f in self.fish_list)
        return current_load / self.capacity if self.capacity > 0 else 0.0
    
    def __str__(self) -> str:
        capacity_pct = int(self.get_capacity_ratio() * 100)
        return f"🏺 {self.name} (魚:{len(self.fish_list)}匹, 容量:{capacity_pct}%)"

"""
Fishクラスのユニットテスト
"""

import pytest
from models.fish import Fish


def test_fish_creation():
    """魚の作成テスト"""
    fish = Fish(species="goldfish", name="金太郎")
    assert fish.species == "goldfish"
    assert fish.name == "金太郎"
    assert fish.health == 100
    assert fish.hunger == 0


def test_feed_fish():
    """餌やりのテスト"""
    fish = Fish(species="goldfish")
    fish.hunger = 50
    fish.feed(30)
    assert fish.hunger == 20


def test_fish_status_update_good_environment():
    """良好な環境での状態更新テスト"""
    fish = Fish(species="goldfish")
    initial_health = fish.health
    
    good_water = {
        'temperature': 25.0,
        'ph': 7.0,
        'cleanliness': 90
    }
    
    fish.update_status(good_water)
    # 空腹度は増えるが、健康は維持される
    assert fish.hunger > 0


def test_fish_status_update_bad_environment():
    """悪い環境での状態更新テスト"""
    fish = Fish(species="goldfish")
    initial_health = fish.health
    
    bad_water = {
        'temperature': 15.0,  # 低すぎる
        'ph': 9.0,  # 高すぎる
        'cleanliness': 30
    }
    
    fish.update_status(bad_water)
    assert fish.health < initial_health
    assert fish.stress_level > 0


def test_fish_growth():
    """成長のテスト"""
    fish = Fish(species="goldfish")
    initial_size = fish.size
    fish.health = 80
    fish.grow()
    assert fish.size > initial_size
    assert fish.age == 1


def test_calculate_happiness():
    """幸福度計算のテスト"""
    fish = Fish(species="goldfish")
    fish.health = 100
    fish.hunger = 10
    fish.stress_level = 5
    happiness = fish.calculate_happiness()
    assert 0 <= happiness <= 100
    assert happiness > 80  # 健康で空腹でないので高い


if __name__ == "__main__":
    pytest.main([__file__, "-v"])
