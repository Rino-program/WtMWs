# バーチャル水族館ゲーム - 段階的開発ガイド

このディレクトリには、バーチャル水族館ゲームを段階的に開発するための完全なガイドが含まれています。

## 📖 概要

このガイドは、ゲーム開発を**段階的**に進めるための詳細な手順書です。各フェーズは独立しており、前のフェーズが完成してから次に進むことができます。

## 🗺️ フェーズ構成

### Phase 0: MVP（最小限の機能）
- **目安**: 2-3日
- **内容**: まず動くものを作る
- **ファイル**: [phase0.html](phase0.html)
- **完成物**: 基本的な魚の追加・表示ができるCLIゲーム

### Phase 1: 基本構造の実装
- **目安**: 3-4日
- **内容**: しっかりとしたクラス設計と実装
- **ファイル**: [phase1.html](phase1.html)
- **完成物**: 完全なFish、Tank、Aquarium、Equipment、Decorationクラス

### Phase 2: ゲームロジックの実装
- **目安**: 4-5日
- **内容**: シミュレーションとゲームエンジン
- **ファイル**: [phase2.html](phase2.html)
- **完成物**: 時間経過、状態変化、経済システムが動作するゲーム

### Phase 3: UIの実装
- **目安**: 2-3日
- **内容**: 使いやすいコマンドラインインターフェース
- **ファイル**: [phase3.html](phase3.html)
- **完成物**: cmdモジュールを使用した快適なCUI

### Phase 4: データファイルの作成
- **目安**: 2-3日
- **内容**: ゲームコンテンツの追加
- **ファイル**: [phase4.html](phase4.html)
- **完成物**: 魚種、装備、装飾のJSONデータ

### Phase 5: 追加機能の実装
- **目安**: 3-4日
- **内容**: ゲームを豊かにする機能
- **ファイル**: [phase5.html](phase5.html)
- **完成物**: セーブ/ロード、イベント、実績システム

### バグ対策と改善
- **目安**: 継続的
- **内容**: 品質向上とメンテナンス
- **ファイル**: [bugfix.html](bugfix.html)
- **活動**: デバッグ、パフォーマンス改善、リファクタリング

## 🚀 使い方

### ローカルでプレビュー

```bash
# このディレクトリに移動
cd docs/game-design-site/phased-guide

# Pythonの組み込みHTTPサーバーを起動
python -m http.server 8000

# ブラウザで http://localhost:8000 を開く
```

### 直接ファイルを開く

```bash
# メインページを開く
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

## 💡 開発のコツ

### 🎯 小さく始める
Phase 0のMVPから始めて、動くものを早く作りましょう。

### ✅ こまめにテスト
各機能を実装したら、すぐにテストを書いて動作確認。

### 📝 ドキュメントを読む
各フェーズのページには詳細な説明があります。わからないことがあったら何度も読み返しましょう。

### 🔄 反復する
一度で完璧にする必要はありません。後から改善できます。
