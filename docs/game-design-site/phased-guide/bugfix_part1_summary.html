🐛 バグ大百科 - 20種類以上のバグと解決方法（600行）

Bug #1: 魚が消える

原因: リスト走査中の削除による順番ずれ


# ❌ 間違い
for fish in aquarium.fish_list:
    if fish.health <= 0:
        aquarium.fish_list.remove(fish)  # イテレータ破壊

# ✅ 正しい
aquarium.fish_list = [f for f in aquarium.fish_list if f.health > 0]

Bug #2: 所持金がマイナスになる

原因: 購入前の残高チェック不足


# ❌ 間違い
def buy_fish(self, fish, price):
    self.money -= price  # マイナスになる可能性

# ✅ 正しい
def buy_fish(self, fish, price):
    if self.money < price:
        raise ValueError("資金不足")
    self.money -= price

Bug #3: セーブファイル破損

原因: 書き込み途中の例外


# ❌ 間違い
with open('save.json', 'w') as f:
    json.dump(data, f)  # 途中で失敗すると破損

# ✅ 正しい
temp_file = 'save.json.tmp'
with open(temp_file, 'w') as f:
    json.dump(data, f)
os.replace(temp_file, 'save.json')  # アトミック操作
