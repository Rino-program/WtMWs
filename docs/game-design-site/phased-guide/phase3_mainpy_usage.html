ステップ 6main.pyの更新とゲームの起動

すべての機能を統合したmain.pyを作成します。これがゲームのエントリーポイントになります。

💻 完全なコード（main.py）：

#!/usr/bin/env python3
"""
バーチャル水族館ゲーム - メインエントリーポイント
Phase 3: UI統合版

ゲームの起動と初期化を行います
"""

import sys
import argparse
from pathlib import Path

# プロジェクトルートをパスに追加
project_root = Path(__file__).parent
sys.path.insert(0, str(project_root))

from ui.cli import AquariumCLI
from ui.display import Display, Colors


def print_welcome():
    """ウェルカムメッセージを表示"""
    welcome_art = f"""
{Colors.BRIGHT}{Colors.CYAN}
    ╔═══════════════════════════════════════════════════════╗
    ║                                                       ║
    ║       🌊 バーチャル水族館ゲーム 🌊                       ║
    ║                                                       ║
    ║       あなただけの水族館を経営しよう！                    ║
    ║                                                       ║
    ║       Version 1.0 (Phase 3)                          ║
    ║                                                       ║
    ╚═══════════════════════════════════════════════════════╝
{Colors.RESET}
"""
    print(welcome_art)
    print(f"{Colors.GREEN}ゲームを起動しています...{Colors.RESET}\n")


def check_dependencies():
    """
    必要な依存パッケージをチェック
    
    Returns:
        bool: すべての依存関係が満たされていればTrue
    """
    required_packages = {
        'colorama': 'colorama',
        'tabulate': 'tabulate',
    }
    
    missing_packages = []
    
    for package_name, import_name in required_packages.items():
        try:
            __import__(import_name)
        except ImportError:
            missing_packages.append(package_name)
    
    if missing_packages:
        Display.print_error("必要なパッケージがインストールされていません：")
        for package in missing_packages:
            print(f"  - {package}")
        print(f"\n{Colors.YELLOW}以下のコマンドでインストールしてください：{Colors.RESET}")
        print(f"  pip install {' '.join(missing_packages)}")
        return False
    
    return True


def parse_arguments():
    """
    コマンドライン引数を解析
    
    Returns:
        argparse.Namespace: 解析された引数
    """
    parser = argparse.ArgumentParser(
        description='バーチャル水族館ゲーム',
        formatter_class=argparse.RawDescriptionHelpFormatter,
        epilog="""
使用例:
  python main.py              # 通常起動
  python main.py --debug      # デバッグモードで起動
  python main.py --help       # ヘルプ表示
        """
    )
    
    parser.add_argument(
        '--debug',
        action='store_true',
        help='デバッグモードで起動'
    )
    
    parser.add_argument(
        '--no-color',
        action='store_true',
        help='カラー出力を無効化'
    )
    
    parser.add_argument(
        '--version',
        action='version',
        version='バーチャル水族館ゲーム v1.0 (Phase 3)'
    )
    
    return parser.parse_args()


def setup_logging(debug_mode=False):
    """
    ロギングを設定
    
    Args:
        debug_mode: デバッグモードの有効/無効
    """
    import logging
    
    level = logging.DEBUG if debug_mode else logging.INFO
    format_str = '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    
    logging.basicConfig(
        level=level,
        format=format_str,
        handlers=[
            logging.FileHandler('aquarium_game.log'),
            logging.StreamHandler()
        ]
    )
    
    if debug_mode:
        Display.print_info("デバッグモードが有効です")
        Display.print_info(f"ログファイル: aquarium_game.log")


def main():
    """メイン関数"""
    try:
        # コマンドライン引数を解析
        args = parse_arguments()
        
        # ウェルカムメッセージ
        if not args.no_color:
            print_welcome()
        
        # 依存関係チェック
        if not check_dependencies():
            sys.exit(1)
        
        # ロギング設定
        setup_logging(args.debug)
        
        # CLIを起動
        Display.print_success("ゲームを開始します！")
        print()
        
        cli = AquariumCLI()
        
        # カラー出力の設定
        if args.no_color:
            # カラーを無効化（実装例）
            pass
        
        # メインループ
        cli.cmdloop()
        
    except KeyboardInterrupt:
        print(f"\n\n{Colors.YELLOW}ゲームを中断しました{Colors.RESET}")
        Display.print_info("またのご来館をお待ちしています！")
        sys.exit(0)
        
    except Exception as e:
        Display.print_error(f"予期しないエラーが発生しました: {e}")
        
        if args.debug:
            import traceback
            traceback.print_exc()
        
        sys.exit(1)
    
    finally:
        # クリーンアップ処理
        print(f"\n{Colors.GREEN}ゲームを終了しました{Colors.RESET}")


if __name__ == "__main__":
    main()

💡 ゲームプレイのヒント

効率的にゲームを進めるためのヒントとコツです。

💰 資金管理のコツ

  • 初期は無理に魚や水槽を増やさない
  • 毎日の支出（餌代、維持費）を把握する
  • reportコマンドで収支予測を確認
  • 評判が高まると収入が増える
  • 資金が10,000円を下回ったら注意

🐠 魚の管理のコツ

  • 毎日必ず餌をやる（feedコマンド）
  • 清潔度が70%を下回ったら掃除（clean）
  • list fishで健康状態を定期的にチェック
  • 病気の魚は早めに対処（健康度30%以下は要注意）
  • 水槽の容量に注意（過密は避ける）

🏆 実績解除のコツ

  • "First Steps" - 初期状態で解除済み
  • "Week Survivor" - 7日間生き残る
  • "Collector" - 色々な種類の魚を集める
  • "Wealthy" - 資金を10,000円以上にする
  • achievementsで進捗確認

⚙️ 効率的なプレイ

  • skipコマンドで時間を効率的に進める
  • 装備を購入して水質管理を自動化
  • 複数の水槽で種類を分けて管理
  • 定期的にreportで分析
  • イベントが発生したら内容を確認

🎯 目標設定の例

  • 初心者目標： 30日間生存
  • 中級者目標： 5種類の魚を集める
  • 上級者目標： 3つの水槽で20匹を管理
  • マスター目標： 評判80以上、資金50,000円以上
🎮 楽しみ方
自分なりのプレイスタイルを見つけましょう！
• のんびり1日ずつ進める
• skipで一気に進めて結果を見る
