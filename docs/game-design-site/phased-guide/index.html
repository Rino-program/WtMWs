📖 このガイドの学習アプローチ

各フェーズでは、以下の4つの視点から学習を進めていきます：

1️⃣ 何を作るか（What to Build）

各フェーズで実装する機能や構造を明確に説明します。ゴールを理解することで、作業の方向性が見えてきます。

  • 実装する機能のリスト
  • 完成時の動作イメージ
  • 達成すべき要件

2️⃣ なぜ作るか（Why Build This）

なぜこの機能が必要なのか、なぜこの設計を採用するのかを説明します。理由を理解することで、応用力が身につきます。

  • 機能の目的と役割
  • 設計の理由と背景
  • 他の選択肢との比較

3️⃣ どう作るか（How to Build）

具体的な実装手順を、ステップバイステップで説明します。迷わず進められるように、詳細な説明とコード例を提供します。

  • 段階的な実装手順
  • 完全なコード例と解説
  • テストと検証方法

4️⃣ どう書くか（Coding Style & Best Practices）

読みやすく保守しやすいコードを書くための、スタイルとベストプラクティスを学びます。

  • 命名規則とコーディング規約
  • コメントとドキュメントの書き方
  • エラー処理とデバッグのコツ

💭 コーディング学習の心構え

このガイドを効果的に活用するための学習姿勢について説明します。

🔍 理解してから実装する

コードをコピー＆ペーストする前に、なぜそのコードが必要なのかを理解しましょう。各セクションの説明を読み、目的を把握してから実装に移ります。

✍️ 自分の言葉でコメントを書く

コード例をそのまま使うのではなく、自分の理解に基づいてコメントを書き直すことで、より深く学べます。

🧪 実験しながら学ぶ

提供されたコードを少し変更してみて、どう動作が変わるか試してみましょう。失敗も学習の一部です。

📝 メモを取る

学んだことや疑問点を記録しておくと、後で復習するときに役立ちます。特に「なぜ」の部分をメモすることが重要です。

🎓 各フェーズで学べること

📚 Phase 0-1: プログラミングの基礎

  • クラス設計: オブジェクト指向プログラミングの実践
  • データ構造: リスト、辞書、クラスの使い分け
  • コーディング規約: 読みやすいコードの書き方

⚙️ Phase 2: ロジックとアルゴリズム

  • 状態管理: ゲーム状態の更新と管理
  • 計算ロジック: 数値計算とシミュレーション
  • 条件分岐: 複雑な条件の整理方法

💻 Phase 3: ユーザーインターフェース

  • 入力処理: ユーザー入力の受け取りと検証
  • 出力フォーマット: 見やすい表示の作り方
  • エラーハンドリング: 適切なエラーメッセージ

📦 Phase 4-5: データとシステム設計

  • データ管理: JSONファイルの読み書き
  • 永続化: セーブ/ロード機能の実装
  • 拡張性: メンテナンスしやすい設計

🗺️ 開発の流れ

Phase 0

MVP（最小限の機能）

まず動くものを作る - 最小限の機能で完成させる

  • 基本的な水槽管理
  • 魚の追加・表示
  • 簡単なコマンド操作
⏱️ 目安: 2-3日
Phase 1

基本構造の実装

しっかりとしたクラス設計と実装

  • 全クラスの定義
  • データ構造の整備
  • ユニットテスト
⏱️ 目安: 3-4日
Phase 2

ゲームロジックの実装

シミュレーションとゲームエンジン

  • 時間経過処理
  • 魚の状態変化
  • 水質変化システム
⏱️ 目安: 4-5日
Phase 3

UIの実装

使いやすいコマンドラインインターフェース

  • コマンド処理
  • 表示フォーマット
  • ヘルプシステム
⏱️ 目安: 2-3日
Phase 4

データファイルの作成

ゲームコンテンツの追加

  • 魚種データ
  • 装備・装飾データ
  • バランス調整
⏱️ 目安: 2-3日
Phase 5

追加機能の実装

ゲームを豊かにする機能

  • セーブ/ロード
  • イベントシステム
  • 実績システム
⏱️ 目安: 3-4日
継続

バグ対策と改善

品質向上とメンテナンス

  • デバッグ手法
  • パフォーマンス改善
  • コードリファクタリング
⏱️ 目安: 継続的

💡 開発のコツ

🎯 小さく始める

Phase 0のMVPから始めて、動くものを早く作りましょう。完璧を目指さず、まず動作することを優先します。

✅ こまめにテスト

各機能を実装したら、すぐにテストを書いて動作確認。バグを早期に発見できます。

📝 ドキュメントを読む

各フェーズのページには詳細な説明があります。わからないことがあったら何度も読み返しましょう。

🔄 反復する

一度で完璧にする必要はありません。後から改善できます。まずは要件を満たすことに集中しましょう。

📚 準備するもの

🐍

Python 3.9以上

型ヒントなどの新機能を使用します

python --version
📦

pip（パッケージマネージャー）

必要なライブラリをインストールします

pip install pytest
💻

テキストエディタ/IDE

VS Code、PyCharm、またはお好みのエディタ

📁

プロジェクトフォルダ

作業用のディレクトリを準備します

mkdir virtual-aquarium && cd virtual-aquarium
