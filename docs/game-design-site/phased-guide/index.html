🗺️ 開発の流れ

Phase 0

MVP（最小限の機能）

まず動くものを作る - 最小限の機能で完成させる

  • 基本的な水槽管理
  • 魚の追加・表示
  • 簡単なコマンド操作
⏱️ 目安: 2-3日
Phase 1

基本構造の実装

しっかりとしたクラス設計と実装

  • 全クラスの定義
  • データ構造の整備
  • ユニットテスト
⏱️ 目安: 3-4日
Phase 2

ゲームロジックの実装

シミュレーションとゲームエンジン

  • 時間経過処理
  • 魚の状態変化
  • 水質変化システム
⏱️ 目安: 4-5日
Phase 3

UIの実装

使いやすいコマンドラインインターフェース

  • コマンド処理
  • 表示フォーマット
  • ヘルプシステム
⏱️ 目安: 2-3日
Phase 4

データファイルの作成

ゲームコンテンツの追加

  • 魚種データ
  • 装備・装飾データ
  • バランス調整
⏱️ 目安: 2-3日
Phase 5

追加機能の実装

ゲームを豊かにする機能

  • セーブ/ロード
  • イベントシステム
  • 実績システム
⏱️ 目安: 3-4日
継続

バグ対策と改善

品質向上とメンテナンス

  • デバッグ手法
  • パフォーマンス改善
  • コードリファクタリング
⏱️ 目安: 継続的

💡 開発のコツ

🎯 小さく始める

Phase 0のMVPから始めて、動くものを早く作りましょう。完璧を目指さず、まず動作することを優先します。

✅ こまめにテスト

各機能を実装したら、すぐにテストを書いて動作確認。バグを早期に発見できます。

📝 ドキュメントを読む

各フェーズのページには詳細な説明があります。わからないことがあったら何度も読み返しましょう。

🔄 反復する

一度で完璧にする必要はありません。後から改善できます。まずは要件を満たすことに集中しましょう。

📚 準備するもの

🐍

Python 3.9以上

型ヒントなどの新機能を使用します

python --version
📦

pip（パッケージマネージャー）

必要なライブラリをインストールします

pip install pytest
💻

テキストエディタ/IDE

VS Code、PyCharm、またはお好みのエディタ

📁

プロジェクトフォルダ

作業用のディレクトリを準備します

mkdir virtual-aquarium && cd virtual-aquarium

🚀 さあ、始めましょう！

準備ができたら、Phase 0のMVPから始めましょう。最小限の機能で動くゲームを作ることで、開発の流れを掴めます。
