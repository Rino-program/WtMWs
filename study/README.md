# Study Support（ローカル保存・Webのみ）

## 概要
Study Support は、宿題や課題など「やらなければいけないこと」を効率的に進めるためのシンプルな学習補助アプリです。
ポモドーロタイマー + タスク管理 + 自動ログ機能を組み合わせ、データはすべてブラウザ内に保存されます。

## 主な機能

### ポモドーロタイマー
- フォーカス/短休憩/長休憩の自動切替
- ラウンド管理（デフォルト: 4ラウンドで長休憩）
- タブタイトルに残り時間を表示
- 正確な計時（Date.now ベース、タブ非アクティブでもドリフト最小）
- キーボードショートカット対応
  - `Space`: 開始/一時停止
  - `S`: スキップ
  - `R`: リセット
  - `1-3`: タブ切替
  - `+/-`: タスクの量を増減

### タスク管理
- タスクの追加/編集/削除
- フォルダによる分類
- 優先度設定（通常/高/緊急）
- デッドライン設定
- 目標時間・目標量の設定
- タスク完了チェック
- フィルター機能（すべて/未完了/完了済み）

### 自動ログ
- フォーカスセッションの自動記録
- タスク紐づけ
- ラウンド番号、所要時間の記録

### 統計・ダッシュボード
- 今日の統計（合計時間、セッション数、タスク別内訳）
- 週間統計（直近7日間の合計、タスク別内訳、グラフ表示）
- 進捗状況の可視化
- 目標達成率の表示

### データ管理
- JSONエクスポート/インポート
- 自動バックアップ（破損時・定期）
- 完全ローカル保存（プライバシー重視）

### PWA対応
- オフライン動作
- Service Worker による静的キャッシュ
- ホーム画面への追加可能

## 使い方

1. **タスクを追加**: 「➕」ボタンからタスクを追加
2. **タスクを選択**: タスクをクリックして選択（未選択でも開始可能）
3. **タイマー開始**: 「スタート」ボタンをクリック
4. **自動記録**: 集中セッションが自動で記録される
5. **進捗確認**: ダッシュボードで今日/今週の進捗を確認
6. **データ保存**: 設定画面から「エクスポート」でバックアップ

- `studyapp.db.v1`: メインデータ
