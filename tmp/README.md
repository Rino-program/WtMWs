# 🎨 Creative Lab - インタラクティブWebデモ集

美しくインタラクティブなWebアプリケーション・ゲーム・ツールのコレクションです。
すべてのアプリはHTML/CSS/JavaScriptのみで作成されており、サーバー不要でブラウザだけで動作します。

## 🚀 使い方

1. `index.html`をブラウザで開く
2. 好きなアプリをクリック
3. 楽しむ！

すべてのアプリはオフラインで動作します（一部の機能を除く）。

## 💻 技術スタック

- **HTML5** - セマンティックマークアップ
- **CSS3** - Flexbox, Grid, アニメーション, Blur効果
- **JavaScript (ES6+)** - Canvas API, Web Audio API, LocalStorage
- **レスポンシブデザイン** - モバイル・タブレット対応

## 📱 ブラウザ対応

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+
